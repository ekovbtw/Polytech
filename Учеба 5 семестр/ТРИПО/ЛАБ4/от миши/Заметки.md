### Подготовка к исследованию
1) Распаковка tar архива
```bash
tar -xf mt3000-4.11.2_release1-1222-1124-1795496384.tar
```

2) Определяем тип содержимого по заголовкам через команду file
```bash
file sysupgrade-glinet_gl-mt3000/root 
```

3) Разорхивация Squashfs образа в папку rootfs
```bash
unsquashfs -d rootfs sysupgrade-glinet_gl-mt3000/root
```

4) Более глубокий анализ файла на поиск всех заголовков
```bash
binwalk sysupgrade-glinet_gl-mt3000/root
```

### Осмотр бинарников
1) Выдать все elf файлы в папке rootfs
```bash
find rootfs -type f -exec file {} \; | grep ELF | less
```
- `{bash} find rootfs ` — рекурсивно обходит папку `rootfs` и все вложенные в нее подкаталоги
- `{bash} -type f` — отбирает только обычные файлы (игнорирует папки, символические ссылки, сокеты и устройства)
- `{bash} -exec file {} \;` — для каждого найденного файла запускает команду `file`:
	- `{}` — сюда подставляется путь к текущему найденному файлу
	- `\;` — экранированная точка с запятой, которая указывает `find`,  где заканчивается команда для `-exec`
- `| grep ELF` — фильтрует вывод find и выводит только те строки, где есть ELF
- `| less` — открывает отфильтрованный список в интерактивном пейджере, чтобы вывод не улетел за пределы экрана терминала. Можно листать его стрелками, искать по тексту через `/` и выйти клавишей `q`
