**Статический анализ** - изучение файла без его запуска: например дизассемблер, прогон через VirusTotal. 
**Динамический анализ** - изучение файла с запуском, наблюдение за поведением файла при его запуске: какие процессы запускаются, что пишет в реестр, какой трафик гуляет по сети. 
**Bridged** - тип подключения ВМ к сети. ВМ видит IP локальной машины, также ВМ видна другим локальным машинам, как хост. Имеет прямой доступ к физической сети. 
**NAT** - ВМ находится за виртуальным роутером VMware. Не видит локальную машину напрямую, не доступна соседним машинам, выходит в интернет через IP хоста. 
**Host-Only** - ВМ видит только хост, в интернет не выходит. Максимальная изоляция. 
**Хэш** -  математическая функция, которая принимает входные данные и преобразует их в строку фиксированной длины. Для одних и тех же входных данных хэш одинаковый. Если поменять 1 байт, то хэш будет другим. По хэшу нельзя восстановить исходные данные. Хэш часто используют как имя файла: ВПО часто анализируют и сверяют чужие анализы по хэшу файла, а не по его имени. 
**SHA-256** - криптографическая хэш-функция (Secure Hash Algorithm). Выдает результат 256 бит. Выдает результат в 256 бит, 64 шестнадцатеричных символа. 
Проверить хэш файла без его запуска можно с помощью: `Get-FileHash -Algorithm SHA256`
**IoC** - индикатор компрометации (Indicator of Compromise), признак по которому можно узнать заражена ли система конкретным вирусом.

**RAT** (Remote Access Trojan) - троян удаленного доступа: предоставляет полный контроль злоумышленнику над машиной. (кейлоггинг, кража паролей, скриншоты, закачка файлов). 
**Remcos** - коммерческий RAT, часто продается под предлогом инструмента для удаленного администрирования. Используется в атаках. **Rescoms** тоже самое.
**Gorgon Group** - APT-группа, известная тем, что не пишет собственные RAT, а использует уже готовые. Доставляют через фишинговые документы Office. 

### IoC
Проверка файла показала, что он копирует себя под предлогом EXCEL. В путь: `C:\Users\Administrator\AppData\Roaming\EXCEL\EXCEL.exe`.
Прописывает ключ реестра: `HKEY_CURRENT_USER\Software\remcos_bjynqcwqnb\EXEpath`. 
Создается во временной папке `install.bat`
Вызывается `PING 127.0.0.1 -n 2`
`install.bat` после запуска удаляется
Обращение по TCP на `115.186.136.237:9999`
Мьютексы `Remcos_Mutex_Inj`, `remcos_bjynqcwqnb`.

### Хронология запуска
По таким данным можно примерно восстановить хронологию запуска: 
1. Запуск сэмпла. Его задача скачать Remcos.
2. Установка Remcos, скрывается под маской excel
3. Прописывает пути в реестр 
4. Запускает Remcos 
5. Remcos создает mutex, чтобы не запуститься дважды
6. Открывает TCP канал с оператором. Пишет logs.dat (кейлогер)
7. Удаляет install.bat, временные файлы.
