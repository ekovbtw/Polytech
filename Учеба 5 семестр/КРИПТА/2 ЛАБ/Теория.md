## Малая теорема Ферма
Если `p` — **простое** число, а `a` не делится на `p`, то  
$$a^{p-1} \bmod p = 1$$
Причем, **свидетель** - такое число *a*, которое при $a^{n-1} \bmod n$ не дает единицу. Как бы разоблачает число *n*, что оно составное, согласно *теореме Ферма*.
**Лжесвидетель** - такое число *a*, которое при: *n* - составное, $a^{n-1} \bmod n$ дает единицу, хотя согласно *теореме Ферма* составное число не должно давать единицу.

## Тест Ферма
Чтобы проверить число *n* нужно:
1. Считаем остаток числа *a* в степени *n-1* по *mod n*
2. Если остаток равен 1, то для этого числа *a* число *n* простое, а значит берем следующее *a*
3. Если остаток не равен 1, то число *n* - составное
4. Если прошли несколько оснований и все дали 1, то число *n* - простое

```
import math


def fermat_test(n, a):

    if math.gcd(a, n) != 1:

        return "составное"

  

    if pow(a, n - 1, n) == 1:

        return "псевдопростое"  

    else:

        return "составное"
```

## Тест Соловэй-Штрассен
Поскольку тест Ферма может не дойти до такого значения *a*, которое покажет, что число *n* составное, или идти долго, используем более узкий тест Соловэя-Штрассена. 
Этот тест берет более тонкое условие: вместо степени *n-1* он берет половину степени $(n-1)/2$, а также проверяет сравнение относительно **символа Якоби**: 
$$a^{(n-1)/2} \bmod n = \left(\frac{a}{n}\right) \bmod n$$
Справа *символ Якоби*, который принимает значения -1, 0, +1. Заметим, что $(n-1)/2$ должно быть целым, а значит число *n* - нечетное.

### Символ Лежандра
Число *a/p* называется **символом Лежандра**. Символ Лежандра показывает: есть ли такое число *x*, что *x² ≡ a (mod p)*. В итоге для числа *a* получается **метка** - число -1, 0, +1, показывающее, является ли оно вычетом (находится ли оно в множестве квадратов по модулю p) числа *p*. 

Пример:
Рассмотрим число 7: остатки этого числа 1...6 
$1^2 = 1$
$2^2 = 4$
$3^2 = 9$ 
$4^2 = 16$
$5^2 = 25$
$6^2 = 36$
Тогда набор остатков по модулю 7 из квадратов: 1, 4, 2, 2, 4, 1. Получается, что числа 1, 2, 4 - вычеты, то есть для них *метка* равна 1. Остальные же числа 3, 5, 6 не являются вычетами, следовательно для них *метка* = -1. 

Если числа большие, то квадраты считать очень долго. Используют формулу $a^{(p-1)/2}  \bmod p$, которая при вычислении показывает тоже самое. 

Для числа *n* используется такая же логика, но с символом *Якоби*. 
Если слева число совпадет с числом справа, то можно считать, что *n* - псевдопростое, иначе составное. 


## Тест Рабин-Миллер
Если число *n* - простое, то сравнение *x² ≡ 1 (mod n)* имеет два решения: $x = 1, x = n-1.$ То есть +1, -1. 
Если число *n* - составное, то это же сравнение может дать нетривиальные корни, отличающиеся от +1 и -1. 

Корни уравнения можно найти перебором, но это займет много времени. Нужно взять всевозможные остатки от *n* и найти такие, которые при возведении в квадрат дают остаток 1. Такие числа будут корнями уравнения. 

Сначала: алгоритм раскладывает число $n-1 = 2^S*d$, где S - количество делений на 2, а d - оставшиеся нечетное число. 
Тогда $a^{n-1} = a^{2^S*d} = (a^{d})^{2^S}$, то есть сначала считаем $a^d$, а затем возводим *S* раз в квадрат. Каждое возведение в квадрат потенциально находит корни. 

Число *n* пройдет проверку, если выполнено хотя бы одно из двух условий: 
1. Самое первое $a^d$ mod n дает единицу (дальше все единицы)
2. Если в множестве $a^d$ квадратов встретится такое число *n-1* 

Если никакое не выполнено, то *n* - составное, а число *a* - свидетель.
