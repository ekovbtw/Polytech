## ρ-метод Полларда
Суть алгоритма, найти для числа *n* такое вспомогательное *z*, при котором выполняется *1<N = МОД(z,n)<n*. Тогда *n/N* даст второй делитель числа *n*. 
В этом методе вспомогательное число *z* получают через разность двух чисел: *z = a-b*. 
Числа *a* и *b* получаются по правилу: **следующее число= (текущее число^2+1)mod n**

```
a = f(a)       # один переход
b = f(f(b))    # два перехода
d = gcd(abs(a - b), n)
```

![[Pasted image 20261111021325.png]]

Условие остановки алгоритма: 
Если *d = gcd(abs(a-b), n)* не равен 1 или n, то выходим. 

## Метод Полларда p-1
Пусть *p* делитель числа *n*. 
По малой теореме Ферма: 
![[Pasted image 20261111025729.png]]

Выражение: 
![[Pasted image 20261111025907.png]]
Может дать искомый делитель при *M кратное p-1*

Алгоритм звучит так: 
1. Выбрать границу значения *B* (выбираем самостоятельно, чем больше B, тем больше вычислений, при этом гарантии успеха нет) и основания a (обычно выбирают взаимно простым с n)
2. Проверить НОД (a, n), если 1<НОД<n, то делитель найден
3. Иначе задать *M = НОК (1...B)*. Также можно задать *M*, как произведение простых чисел, в степени не превосходящих B, до B. 
4. Вычислить *A = (a)^M mod n* 
5. Посчитать *НОД (A-1,n)* 
6. Если *1<НОД<n*, то найден делитель. Иначе попытка неудачная, нужно увеличивать *B* или изменить параметр *a*

## Метод квадратичного решета
Суть в том, чтобы найти пару чисел *(s,t)* такую, что: 
![[Pasted image 20261111032537.png]]
Тогда $n | (s^2 - t^2$). 
И можно попробовать выделить делитель через *МОД (s-t,n)*
![[Pasted image 20261111032916.png]]
Обычно *f(x)* не является квадратом, тогда берут несколько значений *f(x)* и перемножают их, чтобы произведение было квадратом. ![[Pasted image 20261111033007.png]]

Алгоритм: 
1. Берем целое число (округляем вверх) *m*
2. Считаем *f(x)*$$m=\lceil\sqrt n\rceil,\qquad f(x)=(m+x)^2-n.$$
3. Для каждого *x* $$(m+x)^2\equiv f(x)\pmod n.$$
4. Задаем границу *B* (произвольно). В базу включаем 2 и нечетные простые до *B*. 
5. Выбираем интервал значений *x*. Для каждого числа *f(x)* пытаемся разложить по базе. Если раскладывается - то считаем гладким. Сохраняем значения и его разложение.
6. Ищем два разложения, в котором все степени четные. Пробуем представить их произведение как квадрат. 
7. Вычисляем: $$s=\prod_{i\in I}(m+x_i)\bmod n,\qquad t=\sqrt{\prod_{i\in I}f(x_i)}\bmod n.$$
8. Вычисляем НОД: $$d_1=\gcd(|s-t|,n),\qquad d_2=\gcd(s+t,n).$$
9. Если 1<НОД<n, остановка

## Метод непрерывных дробей
Пробуем найти дробь: $$\frac{P_i}{Q_i}\approx\sqrt n.$$
Поскольку приближения малы, то разность $$r_i=P_i^2-nQ_i^2.$$ мала. 
Следовательно: $$P_i^2\equiv r_i\pmod n.$$
Алгоритм: 
1. Проверить не является ли *n* полным квадратом 
2. Выбрать базу и значение *B*
3. Разложить корень из *n* в непрерывную дробь
4. Вычислить остаток: r, сохранить те, которые раскладываются по базе
5. Ищем квадраты через произведения, как в прошлом методе
6. Ищем S и t как в прошлом методе 
7. Вычисляем НОД
