## НОД, алгоритм Евклида 
**НОД** (наибольший общий делитель) - самое большое число, на которое нацело делится (без остатка) набор чисел. 
**Алгоритм Евклида** - НОД пары чисел (a,b) равен НОД между (b, остаток от деления *a на b*). Значит, можно заменить пару (a,b) на пару поменьше (b, остаток) при этом НОД не изменится. Повторяем, пока остаток не станет равным ноль, второе число в паре (b, остаток) и есть искомый НОД.
Почему это верно: 
1. Пусть число d делит a, и b
2. Следовательно число d делит число $a-q*b$, где q - целое. 
3. И наоборот, если d делит b и r, где r - остаток от деления, то оно делит и $a = q*b+r$
Пример: 
- 48 = 2×18 + 12 → переходим к паре (18, 12)
- 18 = 1×12 + 6 → переходим к паре (12, 6)
- 12 = 2×6 + 0 → остаток 0, стоп
НОД = 6. 

## Расширенный алгоритм Евклида
Расширенная версия, которая вдобавок к НОД считает пару коэффициентов u, v таких, что НОД(a,b) = u·a + v·b. Они меняются по точно такому же правилу, что и остатки, только применённому не к числам, а к коэффициентам.
- $r₋₁ = a = 1·a + 0·b →  u₋₁=1, v₋₁=0$
- $r₀ = b = 0·a + 1·b → u₀=0, v₀=1$
А дальше на каждом шаге: 
$uᵢ = uᵢ₋₂ − qᵢ·uᵢ₋₁$  
$vᵢ = vᵢ₋₂ − qᵢ·vᵢ₋₁$

**Если проще**, то: Для НОД(48, 18) = 6 нужно найти два множителя — один для 48, другой для 18 — такие, что если 48 умножить на первый, 18 умножить на второй и сложить, получится 6.
Ответ такой: 6 = (−1)×48 + 3×18.
**Решение:** 
Для простоты обозначим расписанные числа ярлыками.
Распишем первое число таким образом: $ярлык(48) = 1*48+0*18$
Дальше по алгоритму рассматривается число 18: $ярлык(18) = 0*48 + 1*18$
После того как мы расписали первые два числа, выполняем шаг по алгоритму Евклида: $48 = 2*18+12$
Расписываем число 12: $ярлык(12) = ярлык(48) - 2*ярлык(18) = (1,0) - 2*(0,1) = (1,-2)$
Дальше берем следующее число и раскладываем по принципу: *Разность между ярлыком большего числа и произведением ярлыка меньшего числа на частное, которое было при делении.*
То есть: $18 = 1*12+6$
Расписываем: $ярлык(6) = ярлык(18)-1*ярлык(12) = (0,1) - 1*(1,-2) = (-1,3)$
Еще шаг: $12 = 2*6+0$
Расписываем: $ярлык(0) = ярлык(12) - 2*ярлык(6) = (1,-2) - 2*(-1,3) = (3,-8)$
Остановка, когда нашли ноль в остатке. В качестве НОД берем предыдущее значение, то есть число 6.
А следовательно расписанный ответ: $6 = (-1)*48+3*18$

## Бинарный алгоритм Евклида
Практически действуем аналогично.
Три основных правила алгоритма: 
1. Если **оба четные**, то делим оба числа на 2, но запоминаем отдельно. 
2. **Одно четное, другое нечетное**, то четное делим на 2, второе не трогаем. Это безопасно, так как двойка у них не общий делитель. 
3. **Оба нечетные**, вычитаем меньшее из большего. Разница двух нечетных чисел всегда четная, так что на следующем шаге делим на 2.

Пример: пара чисел (100,35) - четное/нечетное. Применяем второе правило, получаем пару (50,35). Применяем опять второе правило, получим (25,35).
