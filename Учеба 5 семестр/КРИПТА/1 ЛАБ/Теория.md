## НОД, алгоритм Евклида 
**НОД** (наибольший общий делитель) - самое большое число, на которое нацело делится (без остатка) набор чисел. 
**Алгоритм Евклида** - НОД пары чисел (a,b) равен НОД между (b, остаток от деления *a на b*). Значит, можно заменить пару (a,b) на пару поменьше (b, остаток) при этом НОД не изменится. Повторяем, пока остаток не станет равным ноль, второе число в паре (b, остаток) и есть искомый НОД.
Почему это верно: 
1. Пусть число d делит a, и b
2. Следовательно число d делит число $a-q*b$, где q - целое. 
3. И наоборот, если d делит b и r, где r - остаток от деления, то оно делит и $a = q*b+r$
Пример: 
- 48 = 2×18 + 12 → переходим к паре (18, 12)
- 18 = 1×12 + 6 → переходим к паре (12, 6)
- 12 = 2×6 + 0 → остаток 0, стоп
НОД = 6. 

## Расширенный алгоритм Евклида
Расширенная версия, которая вдобавок к НОД считает пару коэффициентов u, v таких, что НОД(a,b) = u·a + v·b. Они меняются по точно такому же правилу, что и остатки, только применённому не к числам, а к коэффициентам.
- $r₋₁ = a = 1·a + 0·b →  u₋₁=1, v₋₁=0$
- $r₀ = b = 0·a + 1·b → u₀=0, v₀=1$
А дальше на каждом шаге: 
$uᵢ = uᵢ₋₂ − qᵢ·uᵢ₋₁$  
$vᵢ = vᵢ₋₂ − qᵢ·vᵢ₋₁$

**Если проще**, то: Для НОД(48, 18) = 6 нужно найти два множителя — один для 48, другой для 18 — такие, что если 48 умножить на первый, 18 умножить на второй и сложить, получится 6.
Ответ такой: 6 = (−1)×48 + 3×18.
**Решение:** 
Для простоты обозначим расписанные числа ярлыками.
Распишем первое число таким образом: $ярлык(48) = 1*48+0*18$
Дальше по алгоритму рассматривается число 18: $ярлык(18) = 0*48 + 1*18$
После того как мы расписали первые два числа, выполняем шаг по алгоритму Евклида: $48 = 2*18+12$
Расписываем число 12: $ярлык(12) = ярлык(48) - 2*ярлык(18) = (1,0) - 2*(0,1) = (1,-2)$
Дальше берем следующее число и раскладываем по принципу: *Разность между ярлыком большего числа и произведением ярлыка меньшего числа на частное, которое было при делении.*
То есть: $18 = 1*12+6$
Расписываем: $ярлык(6) = ярлык(18)-1*ярлык(12) = (0,1) - 1*(1,-2) = (-1,3)$
Еще шаг: $12 = 2*6+0$
Расписываем: $ярлык(0) = ярлык(12) - 2*ярлык(6) = (1,-2) - 2*(-1,3) = (3,-8)$
Остановка, когда нашли ноль в остатке. В качестве НОД берем предыдущее значение, то есть число 6.
А следовательно расписанный ответ: $6 = (-1)*48+3*18$

## Бинарный алгоритм Евклида
Практически действуем аналогично.
Три основных правила алгоритма: 
1. Если **оба четные**, то делим оба числа на 2, но запоминаем отдельно. 
2. **Одно четное, другое нечетное**, то четное делим на 2, второе не трогаем. Это безопасно, так как двойка у них не общий делитель. 
3. **Оба нечетные**, вычитаем меньшее из большего. Разница двух нечетных чисел всегда четная, так что на следующем шаге применяем второе правило.

Пример: пара чисел (100,35) - четное/нечетное. Применяем второе правило, получаем пару (50,35). Применяем опять второе правило, получим (25,35). Дальше работает правило 3, получаем пару (25, 10), применяем второе правило, получаем (25,5). Опять правило 3, получили (20,5), дальше правило 2 (10,5), опять правило 2, получаем (5,5). Если оба числа совпали, то останавливаемся. 

Рассмотрим разложение на коэффициенты в бинарном алгоритме: 
Здесь одновременно будет два ярлыка. Начало как обычно: $ярлык 100 = (1,0),   ярлык 35 = (0,1).$
Первым шагом, как описано выше, используем правило 2. Хотим разделить 100 на 2, а также его ярлык. Но в ярлыке (1,0) цифра 1 - нечетная. 
Используем следующую закономерность: 

> [!Закономерность]
> Если в ярлыке хоть одно число нечетное - прибавляем к нему пару (b, -a) = (35, -100). Это не меняет сути так как$(35*100 + (-100)*35 = 0)$. 

На примере: $(1,0) + (35, -100) = (36, -100)$ - теперь оба числа четные
Дальше, как и задумано, делим на 2, получаем $(18,-50)$
Проверка: $18*100 + (-50)* 35 = 1800 - 1750 = 50$. А значит, текущее состояние $x = 50$, с коэффициентами $(18, -50)$.
А $y = 35$ и ярлыком $(0,1)$ так и остался. Получаем пару чисел $(50,35)$, применяем правило 2. Смотрим на ярлык 50, оба числа четные. Значит никаких махинаций не требуется. Делим на 2, получаем (9,-25). 
Проверка: $9*100+(-25)*35 = 25$, что совпадает с $x = 25, y = 35$. Получили пару $(25,35)$. Оба числа нечетные, используем правило 3. Вычитаем из большего меньшее, получаем $(25,10)$, x - остается прежним, а ярлык y - обновляем (вычитаем ярлык x из старого ярлыка): $(0,1) - (9, -25) = (-9, 26)$. 
Проверка: $(-9)*100 + 26*35 = 10$, что совпадает с новым y. Дальше пара чисел (25,10), применяем правило 2. Получаем: (25,5), изменился y, значит меняем его ярлык: (-9,26) - нельзя разделить на два - используем закономерность: $(-9,26) + (35, -100) = (26, -74).$ Получили оба четных числа, делим: (13, -37). 
Проверка: $13*100 +(-37)*35 = 5$, что совпадает с y. Дальше пара чисел (25,5) - оба нечетных, правило 3. Получаем (20,5) и ярлык для x: $(9,-25) - (13, -37) = (-4, 12)$. Получили пару (20,5), применяем правило 2: получаем (10,5), с ярлыком для x: (-2,6). Опять применяем правило 2: (5,5) и ярлык для x = (-1, 3). 
Итог: получили пару чисел (5,5) с ярлыком для x = (-1,3), ярлыком для y = (13,-37)

## Алгоритм с усеченными остатками
В обычном алгоритме, всегда получается остаток от нуля до b-1, то есть неотрицательное значение. Алгоритм с усеченными остатками берет частое с округлением до ближайшего целого. Таким образом остаток может выйти отрицательным, но по модулю меньшим половины делителя. За счет этого спуск к нулю происходит быстрее. 

*Практическое правило*: сначала находим обычное частное и остаток (как в первом алгоритме). Если остаток получился больше половины делителя, увеличиваем частное на 1, а из остатка вычитаем весь делитель целиком (он станет отрицательным, но меньшим по модулю). Если остаток не больше половины - оставляем. 

На примере: возьмем пару чисел $(100,35)$: обычное частное $100:35 = 2$, остаток 30, а половина от $35 = 17,5$. Получаем, что $30>17,5$, следовательно к частному прибавляем единицу, а из остатка вычитаем делитель: $100:35=3$, $остаток = -5$
Считаем ярлык: $ярлык(-5) = ярлык (100) - 3*ярлык(35) = (1,0) - 3*(0,1) = (1,-3)$
Следующий шаг: 35 делим на (-5), получаем (-7). Без остатка, то есть следующий будет 0.
$Ярлык (-7) = Ярлык (35) - (-7)*(ярлык (-5)) = (0,1) - (-6)*(1,-3) = (7, -20)$ 
Если остаток 0, то число (-5) нас будет интересовать как НОД. Раз остаток отрицательный, то превратим его в положительный: 5, ярлыком (-1,3). Проверим: $ЛК = (-1)*100+3*35 = 5$. Результат совпал.
