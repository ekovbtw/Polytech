**Дискретный логарифм** числа *x* по основанию *a* числа *b* и модулю *p* - называется показатель степени, удовлетворяющий сравнению: 
$a^x\equiv b\pmod p$. 
Он называется дискретным, потому что значение *x* рассматривается на конечном дискретном множестве остатков степеней числа *a* по модулю *p*. В обычной математике - логарифм рассматривается на бесконечном вещественном множестве чисел. 
**Порядок элемента** - наименьшее положительное целое число *q*, для которого верно: ${a^q\equiv1\pmod p}$  
![[Pasted image 20261123135022.png]]
На этом примере: порядок числа 13 равен 4.  

В диапазоне от *1* до *q-1* собраны различные значения степеней числа *a* по модулю *p*, кроме единицы. 
Если *q* - порядок, то  $a^q\equiv1\pmod p,$ а следовательно $a^{x+kq}\equiv a^x\pmod p.$ 

**Циклическая подгруппа** - $\langle13\rangle=\{1,13,16,4\}.$ Это множество чисел, которые можно получить возведением основания *a* в целые степени по заданному модулю *p*. Чтобы дискретный логарифм существовал необходимо, чтобы число *b* принадлежало циклической подгруппе. 

**Обратным элементом** числа *a* называется такое число *b*, которое при умножении на число *a* дает остаток *1* по модулю *p*. Он существует если *НОД(a,p) = 1* 
Например: $13^{-1}\pmod{17}$ - найти обратный элемент числа 13.
$13\cdot4=52.$
А поскольку:
$52=3\cdot17+1,$
получаем:
$13\cdot4\equiv1\pmod{17}.$
Следовательно:
${13^{-1}\equiv4\pmod{17}}.$ 

То есть, обратный элемент числа 13 - число 4. 

Отрицательная степень в модульной арифметике означает использование обратного элемента:
$13^{-3}\equiv4^3\equiv13\pmod{17}.$
Таким образом, можно вычислять отрицательные степени числа *a* по модулю *p*. 

Обратный элемент можно найти с помощью расширенного алгоритма Евклида - [[Учеба 5 семестр/ТЧМК/1 ЛАБ/Теория|Теория]]. 
Если в общем, то расширенный алгоритм Евклида помогает выразить коэффициенты *u* и *v* удовлетворяющие равенству: 
$au+mv=\gcd(a,m).$ Если $au+mv=1,$ то ${a^{-1}\equiv u\pmod m}.$ 

# Метод Гельфонда
Метод предлагает разделить поиск неизвестного показателя степени на две части и искать совпадение между ними.
У нас есть:
$a^x\equiv b\pmod p.$

Введём новое число:
$s=\lceil\sqrt q\rceil+1.$

Теперь представим неизвестный показатель \(x\) в виде:
${x=ks+t}$

где:
$0\leq t<s$

Подставляем в исходное сравнение:
$a^{ks+t}\equiv b\pmod p.$

Используем свойство степеней:
$a^{ks}\cdot a^t\equiv b\pmod p.$

Теперь умножим обе части на обратный элемент $(a^{-ks}$):
${a^t\equiv b\cdot a^{-ks}\pmod p}.$

Теперь у нас есть две последовательности:  $a^0,\ a^1,\ a^2,\ldots,a^{s-1}$ и $b,\quad ba^{-s},\quad ba^{-2s},\quad ba^{-3s},\ldots$ 
В этих последовательностях ищут совпадение. Если совпадение найдено: $a^t\equiv ba^{-ks}\pmod p,$ следовательно: ${x=ks+t}$ это и есть дискретный логарифм.

## Пример
$5^x\equiv3\pmod{17}.$
Здесь порядок числа 5 по модулю 17 равен 16, поэтому $s=\lceil\sqrt{16}\rceil+1=5.$ 
Следующим шагом обозначим *x*, как: $x=5k+t.$ 
Получаем: $5^t\equiv3\cdot5^{-5k}\pmod{17}.$
Теперь нам нужно найти совпадение между двумя последовательностями:
Первая:

![[Pasted image 20261123162054.png]]

Вторая: 
Будет строится по формуле: $c_k=3\cdot5^{-5k}\bmod17.$ 
Например: при (k=1): $c_1=3\cdot5^{-4}\bmod17,$ получим ${5^{-5}\equiv11\pmod{17}}.$ $c_1=3\cdot11=16\pmod{17}.$ Совпадений нет, идем дальше 
$c_2=16\cdot11\pmod{17}$ получаем совпадение с первой последовательностью при *t=3*. А значит, что:  $t=3,\ k=2,\ s=5.$ 
Выполняем обратную замену $x=ks+t:$ $x=2\cdot5+3=13.$
Проверяем результат: $5^{13}\equiv3\pmod{17}.$ 

В итоге, алгоритм выглядит так: 
1. Вычисляем $s=\lfloor\sqrt r\rfloor+1$
2. Строим таблицу малых степеней $a^t\bmod p$
3. Вычисляем последовательность $b\cdot a^{-ks}\bmod p$
4. Ищем совпадение между последовательностями.
5. При совпадении восстанавливаем показатель: ${x=ks+t}.$

Сложность по времени и памяти — порядка $O(\sqrt r)$.
где *r* - порядок.

# Метод ро-Полларда
Метод аналогично предыдущему ищет дискретный логарифм: ${a^x\equiv b\pmod p}$. 
Он предлагает использовать специальную функцию *f(c)*: 

$f(c)= \begin{cases} ac\bmod p,&c<p/2,\\ bc\bmod p,&c>p/2. \end{cases}$

где ${c=a^u b^v\bmod p}$, причем *u* и *v* некоторые случайные числа. 
Таким образом, на каждой итерации берем новое, полученное число *c*, прогоняем его через функцию *f(c)*: если число *c* меньше половины *p*, то умножаем на *a*, иначе умножаем на *b*. На выходе получаем псевдослучайную последовательность чисел.
Псевдослучайную последовательность, потому что при одинаковых значениях, получаем одинаковый результат, то есть последовательность детерминирована. 
Поскольку число *c* принадлежит множеству остатков *p*, то, рано или поздно при генерации новых значений, последовательность попадает в цикл. 

Логарифм же, можно выразить следующим образом: 
Поскольку:
$b\equiv a^x\pmod p,$

можем записать:
$c\equiv a^{u+vx}\pmod p.$

Следовательно: 
$\log_a c=u+vx\pmod r.$ 

Для относительно небольшой задачи, можно вычислить левую часть напрямую, поскольку *a* и *c* нам известны, но тогда потребуется решить аналогичную задачу нахождения показателя степени числа *a*. Для небольшой задачи можно перебрать степени в ручную, например:
$\log_5(12)\pmod{16}.$ Для этого переберём степени пятёрки: $5^0\equiv1,$ $5^1\equiv5,$ $\ldots$ $5^9\equiv12\pmod{17}.$
Следовательно:
$\log_5(12)\equiv9\pmod{16}.$
Для большой задачи перебор будет большим, следовательно искать *x* из этого выражения бессмысленно. 

Поэтому используется принцип, при котором *u* и *v* обязательно встретятся в цикле, поскольку они двигаются с разным шагом (отличается на 1) и движутся по одной траектории. 
В конечном итоге ${c=d\pmod p}.$
