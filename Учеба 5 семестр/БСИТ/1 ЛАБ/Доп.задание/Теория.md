**Windows Security Center** - это центральный компонент Windows (служба), который следит за состоянием ключевых механизмов безопасности ОС и сводит информацию о них в одно место. Начиная с Windows 10 встроен в Windows Security, раньше был встроен в центр поддержки. 

### Зачем он нужен 
В системе есть множество утилит для защиты и обеспечения безопасности. Например, антивирусы, автообновления, брандмауэр, часто от разных производителей. Пользователю, в случае проблемы, нужно знать состояние системы (где ошибка, исправна ли система). Чтобы не бегать по разным программам и не собирать отчетность, существует *WSC* (**Windows Security Center**), который собирает всю информацию в одном месте. 

Защитные программы регистрируются в *WSC*, как *security providers* (поставщики безопасности) и сообщают ему свой статус. *WSC* собирает статус, и может в случае чего показать на то, что сломалось или отключено. 


Через API (`wscapi.h`) можно запросить статус по категориям — вот основные:

- `WSC_SECURITY_PROVIDER_ANTIVIRUS` — антивирус;
- `WSC_SECURITY_PROVIDER_FIREWALL` — брандмауэр;
- `WSC_SECURITY_PROVIDER_ANTISPYWARE` — антишпион;
- `WSC_SECURITY_PROVIDER_AUTOUPDATE_SETTINGS` — автообновления;
- `WSC_SECURITY_PROVIDER_INTERNET_SETTINGS` — настройки безопасности интернета;
- `WSC_SECURITY_PROVIDER_USER_ACCOUNT_CONTROL` — контроль учётных записей (UAC);
- `WSC_SECURITY_PROVIDER_SERVICE` — служба WSC как таковая.

У каждой категории статус (`WSC_SECURITY_PROVIDER_HEALTH`):

- `GOOD` — всё в порядке;
- `NOTMONITORED` — WSC это не отслеживает;
- `POOR` — защита есть, но в плохом состоянии (например, устарела);
- `SNOOZE` — временно приостановлено;
- неизвестно — прочее.

Небольшая программа, которая опрашивает состояние антивируса с помощью `wscapi`: 

```
#define _CRT_SECURE_NO_WARNINGS
#include <windows.h>
#include <wscapi.h>              // Windows Security Center API
#include <iostream>
#pragma comment(lib, "wscapi.lib")

int main()
{
    WSC_SECURITY_PROVIDER_HEALTH health;

    // запрашиваем здоровье категории "антивирус"
    HRESULT hr = WscGetSecurityProviderHealth(WSC_SECURITY_PROVIDER_ANTIVIRUS, &health);

    if (FAILED(hr)) {
        std::cout << "WscGetSecurityProviderHealth failed: 0x" << std::hex << hr << std::endl;
        return 1;
    }

    const char* status;
    switch (health) {
    case WSC_SECURITY_PROVIDER_HEALTH_GOOD:          status = "GOOD";          break;
    case WSC_SECURITY_PROVIDER_HEALTH_NOTMONITORED:  status = "NOT MONITORED"; break;
    case WSC_SECURITY_PROVIDER_HEALTH_POOR:          status = "POOR";          break;
    case WSC_SECURITY_PROVIDER_HEALTH_SNOOZE:        status = "SNOOZE";        break;
    default:                                         status = "UNKNOWN";       break;
    }

    std::cout << "Antivirus status: " << status << std::endl;
    return 0;
}
```
