# Основные термины
**Сервис** (служба) - системный процесс, предоставляющий функциональность, не связанную с интерактивным пользователем (работает фоном).
Основные признаки службы: 
1. работает фоном, без окон
2. может запускаться до входа в систему
3. видна в специальном списке services.msc - "Службы" 

**SCM** (Service Control Manager) - системный процесс *Service.exe*, который создает, запускает, останавливает и удаляет службы. Наша служба должна уметь регистрироваться в *SCM*, докладывать ему текущее состояние, ожидать команду STOP. 
**SCP** (Service Control Program) - программа управления сервисом. В ней используются SCM API функции: CreateService, DeleteService, StartService. 

## Процесс запуска
Когда вводим команду `myservice.exe install` происходит следующее: 
1. запускается обычный процесс, с правами от учетной записи
2. в SCP части запускается SCM API 
3. инициализируется служба в реестре (HKLM\SYSTEM\CurrentControlSet\Services)
4. записывается путь к myservice.exe

Когда приходит команда `start`:
1. SCM запускает новый экземпляр myservice.exe

### Проблема
Проблема состоит в том, что процесс не знает ради чего его вызвали: ради *install* регистрации или *start* ради сервиса. 

Как он различает: 
```
if (argc - 1 == 0) {
    // ... StartServiceCtrlDispatcher ...
} else if (wcscmp(argv[argc-1], _T("install")) == 0) {
    InstallService();
}
```

Когда запускает SCM, то аргументов при запуске - нет. Если запускаем мы, то указываем аргументы: install, remove и так далее. Поэтому ветка без аргументов - SCM. 

```
int _tmain(int argc, _TCHAR* argv[]) {
    // Запомним путь к своему exe — понадобится в InstallService()
    GetModuleFileName(NULL, g_servicePath, MAX_PATH);

    if (argc > 1) {
        // Нас запустил ЧЕЛОВЕК с аргументом → режим SCP
        if (_tcscmp(argv[1], _T("install")) == 0) return InstallService();
        else if (_tcscmp(argv[1], _T("remove")) == 0) return RemoveService();
        else if (_tcscmp(argv[1], _T("start")) == 0) return DoStartService();
        else if (_tcscmp(argv[1], _T("stop")) == 0) return DoStopService();
        else { _tprintf(_T("Unknown command\n")); return 1; }
    }

    // Аргументов нет → нас запустил SCM → режим СЕРВИСА
    SERVICE_TABLE_ENTRY ServiceTable[] = {
        { (LPTSTR)SERVICE_NAME, (LPSERVICE_MAIN_FUNCTION)ServiceMain },
        { NULL, NULL }
    };

    if (!StartServiceCtrlDispatcher(ServiceTable)) {
        // Частый код: 1063 — запустили вручную, а не через SCM
        WriteLog("StartServiceCtrlDispatcher failed");
        return 1;
    }
    return 0;
}
```
В этой функции происходит следующее: 
1. Сохраняется путь до исполняемого файла
2. Если есть аргументы, значит запуск из консоли:
	1. `_tcscmp` сравнение строк
3. Если аргументов нет, то вызов из SCM: 
	1. Создаем объект структуры `SERVICE_TABLE_ENTRY` - в ней хранится имя службы и адрес функции ServiceMain, в которой основная работа службы
4. StartServiceCtrlDispatcher - функция, которая передает структуру ServiceTable в SCM. Блокирует поток и не возвращает значение сразу. Ошибка будет, если запущено .exe вручную, а не через SCM. 

## Состояние службы 
Состояние службы - режим, в котором служба сейчас находится: 

- `SERVICE_START_PENDING` — запуск
- `SERVICE_RUNNING` — работа
- `SERVICE_STOP_PENDING` — остановка
- `SERVICE_STOPPED` — стоп

Служба должна постоянно сообщать о своем состоянии SCM. Это происходит следующим образом: 

```
g_ServiceStatus.dwCurrentState = SERVICE_ЧТО_ТО;   // структура, которая хранит статус. записали новое состояние
SetServiceStatus(g_StatusHandle, &g_ServiceStatus); // доложили SCM
```
Жизненный цикл: `START_PENDING → RUNNING → STOP_PENDING → STOPPED`

Запуск службы не всегда происходит мгновенно, также и остановка, поэтому есть промежуточные состояния: запуск и остановка, чтобы SCM точно знал состояние службы (если она зависнет намертво, он бы без этого не узнал). Также в этом состоянии служба может поставить `dwWaitHint` - поле, в котором лежит значение сколько миллисекунд ждать ее запуска, если это время прошло SCM может признать ее зависшей. 

# ServiceMain
```
void WINAPI ServiceMain(DWORD argc, LPTSTR* argv) {
    g_StatusHandle = RegisterServiceCtrlHandler(SERVICE_NAME, ControlHandler);
    if (!g_StatusHandle) return;

    // Сообщаем: стартуем
    ZeroMemory(&g_ServiceStatus, sizeof(g_ServiceStatus));
    g_ServiceStatus.dwServiceType = SERVICE_WIN32_OWN_PROCESS;
    g_ServiceStatus.dwCurrentState = SERVICE_START_PENDING;
    g_ServiceStatus.dwControlsAccepted = 0; // пока ничего не принимаем
    SetServiceStatus(g_StatusHandle, &g_ServiceStatus);

    // Создаём событие остановки (ручной сброс, изначально не сигнально)
    g_StopEvent = CreateEvent(NULL, TRUE, FALSE, NULL);
    if (g_StopEvent == NULL) {
        g_ServiceStatus.dwCurrentState = SERVICE_STOPPED;
        g_ServiceStatus.dwWin32ExitCode = GetLastError();
        SetServiceStatus(g_StatusHandle, &g_ServiceStatus);
        return;
    }

    // Готовы работать: сообщаем RUNNING и что принимаем STOP/SHUTDOWN
    g_ServiceStatus.dwCurrentState = SERVICE_RUNNING;
    g_ServiceStatus.dwControlsAccepted = SERVICE_ACCEPT_STOP | SERVICE_ACCEPT_SHUTDOWN;
    SetServiceStatus(g_StatusHandle, &g_ServiceStatus);
    WriteLog("Service RUNNING");

    // ─── Рабочий цикл ───
    while (WaitForSingleObject(g_StopEvent, 5000) != WAIT_OBJECT_0) {
        // Сюда позже вставим вызов архивации (раз в 5 секунд проверяем папку).
        WriteLog("tick (здесь будет архивация)");
    }

    // Пришёл сигнал остановки → выходим
    CloseHandle(g_StopEvent);
    g_ServiceStatus.dwCurrentState = SERVICE_STOPPED;
    g_ServiceStatus.dwWin32ExitCode = 0;
    SetServiceStatus(g_StatusHandle, &g_ServiceStatus);
    WriteLog("Service STOPPED");
}
```

1. `g_StatusHandle = RegisterServiceCtrlHandler(SERVICE_NAME, ControlHandler);` регистрирует в SCM функцию `ControlHandler` - функцию, через которую происходит управление службой со стороны SCM: 
```
   void WINAPI ControlHandler(DWORD request) {
    switch (request) {
    case SERVICE_CONTROL_STOP:
    case SERVICE_CONTROL_SHUTDOWN:
        WriteLog("STOP/SHUTDOWN received");
        // Сообщаем, что начали останавливаться
        g_ServiceStatus.dwCurrentState = SERVICE_STOP_PENDING;
        SetServiceStatus(g_StatusHandle, &g_ServiceStatus);
        // Будим рабочий цикл
        SetEvent(g_StopEvent);
        break;
    default:
        break;
    }
}
```




# Config
Config.txt 

```
source = C:\backup_src
dest = C:\backup_out
archive = backup.zip
mask = *.txt
mask = *.docx
mask = report?.exe
```

source - папка, которую копируем
dest - куда копируем
archive - имя архива
mask - маска: 
1. * - любое количество символов, например: 
    1. `*.txt - значит, что lalala.txt скопирует lalala полностью`
    2. `lalala* - значит, что скопирует любой тип файла полностью`
    3. `*lalala* - значит, что и слева и справа скопирует полностью`
2. ? - скопирует только один символ
