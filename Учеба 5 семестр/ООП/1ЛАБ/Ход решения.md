## Классы, объекты 

**Класс** - это описание, как структура в C. 
**Объект** - конкретный экземпляр класса. 
В классе есть поля и методы. **Поля** - данные объекта (длина, переменные), **методы** - функции, с которыми работает объект. 
Класс решает проблемы связанные со структурами в языке C. 
Метод вызывается у объекта через точку:

```
a.clear()
int n = b.size()
```
Объект, в отличие от языка C, не передается явно.

Части класса можно закрыть от внешнего мира: 

```
class MyString {
public:               // доступно всем
    int size();
    void clear();

private:              // доступно только методам самого класса
    char* data_;
    int size_;
};
```
поля меняются только через методы, а методы написаны так, чтобы данные всегда оставались правильными.

Это называется **инкапсуляция**. 

**Конструктор** - особый метод, который самостоятельно вызывается при создании объекта. Его задача заполнить поля начальными значениями. 
1. У конструктора имя совпадает с именем класса
2. Нет возвращаемого типа

```
class MyString 
{ 
public: 
	MyString(); // конструктор без аргументов 
	MyString(const char* str); // конструктор от C-строки 
	...
};
```
Конструкторов может быть несколько, вызов конструктора зависит от типа объекта, который создается. 

```
MyString a;            // вызовется MyString()          → пустая строка
MyString b("hello");   // вызовется MyString(const char*) → строка "hello"
```
Самому вызывать конструктор не нужно и нельзя: он срабатывает ровно один раз, в момент рождения объекта. Забыть инициализацию теперь невозможно.

**Деструктор** - пара конструктора. Вызывается самостоятельно при уничтожении объекта. Его задача освободить ресурсы. 
Имя деструктора совпадает с названием класса с тильдой: `~MyString()`

Пример уничтожения объекта - заканчивается функция, в которой он был создан: 

```
{
    MyString s("hello");   // конструктор: выделили память
    ...
}                          // здесь деструктор: память освобождена
```

`-std=c++17` — стандарт C++17, который требует code style; `-Wall -Wextra` включают предупреждения компилятора, они помогут ловить ошибки; `-o test_mystring` задаёт имя исполняемого файла.

**Обертка** (wrapper) - это программа, которая позволяет python использовать классы написанные на языке C++. После сборки получается модуль, который python подключает через import.

Согласно code_style поля в классе оканчиваются на нижнее подчеркивание. Это нужно, чтобы поля и методы имели различные названия.

Добавим объявления в класс:

**const** после скобок нужен, чтобы обозначить компилятору, что объект не изменяется методом, то есть открыт только для чтения. При попытке записать в объект данные геттером будет ошибка.

    return size_ == 0;

Пустая строка вообще не должна выделять память, согласно условию. Сейчас реализация c_str (функция возвращающая указатель на первый элемент string объекта, в котором есть \0), а nullptr (NULL) возвращать нельзя. Решением будет добавить пустой литерал с \0, который хранится в программе постоянно.

        return "";

    return data_;

int MyString::size() const {
    return size_;

    return capacity_;
}

bool MyString::empty() const {

Теперь добавим собственный realloc, который будет выделять больше памяти, если ее не хватает. 
Определим в заголовке:

```
private:
        char* data_;     // pointer to null-terminated buffer
        int size_;       // number of characters, excluding '\0'
        int capacity_;   // allocated memory size, including '\0'
        void ensure_capacity(int new_size);
```

Теперь добавим реализацию в mystring.cpp: 

```
void MyString::ensure_capacity(int new_size) {
    int required_capacity = new_size + 1;
    if (required_capacity <= capacity_) {
        return;
    }
    char* new_data = new char[required_capacity];
    if (data_ != nullptr) {
        std::memcpy(new_data, data_, size_ + 1);
    } else {
        new_data[0] = '\0';
    }
    delete[] data_;
    data_ = new_data;
    capacity_ = required_capacity;
}
```

Теперь добавим главную функцию класса **replace_impl**.

Заметим, что некоторые функции, которые меняют строку являются частными случаями одной и той же операции - "заменить count символов, начиная с index позиции".

Значит достаточно написать одну функцию, а остальные методы станут однострочными вызовами. Это и есть **алгоритмическая декомпозиция**. 

![[Pasted image 20261002031115.png]]

Добавим в заголовочный файл, в private: 

```
void replace_impl(int index, int count, const char* source, int source_length);
```

В cpp объявим реализацию: 

```
#include <stdexcept>
```

```
void MyString::replace_impl(int index, int count, const char* source, int source_length) {
    if (index < 0 || index > size_) {
        throw std::out_of_range("MyString: index out of range");
    }
    if (count < 0 || source_length < 0) {
        throw std::invalid_argument("MyString: negative count");
    }
    if (count > size_ - index) {
        count = size_ - index;
    }

    int new_size = size_ - count + source_length;
    ensure_capacity(new_size);

    int tail_length = size_ - index - count;
    std::memmove(data_ + index + source_length, data_ + index + count, tail_length + 1);
    std::memcpy(data_ + index, source, source_length);
    size_ = new_size;
}
```

**throw** - немедленно прекращает работу функции с диагностическим принтом через метод **what()**.  
**memmove** - работает как memcpy, только изначально проверяет пересекаются ли области копирования данных. Если пересекаются делает копирование справа налево, иначе наоборот. Это нужно так как изначально нет информации, как придется сдвигать хвост. 

Проверим работоспособность функции с помощью конструктора `MyString("Hello")`, то есть взятие пустой строки и вставка в нее текст.
Он должен вызвать `replace_impl(0, 0, str, длина str);   // в позицию 0, убрав 0 символов`. 
В заголовке объявим public: 

```
MyString(const char* str);
```

Добавим реализацию после деструктора: 

```
MyString::MyString(const char* str) : MyString() {
    if (str == nullptr) {
        throw std::invalid_argument("MyString: null pointer");
    }
    replace_impl(0, 0, str, static_cast<int>(std::strlen(str)));
}
```

После названия конструктора пишем `MyString()` для того, чтобы поля изначально были заполнены. 
Объявим в main.cpp: 

```

Напишем конструкторы с количеством символов: `MyString("hello", 4)` берёт из источника только первые 4 символа и даёт `"hell" (4, 5)`. Нужно три версии: для `const char*`, `std::string` и `MyString`.
Например, `MyString("hello", 10)`. Читать 10 символов из 5-символьной строки — выход за пределы памяти. Поэтому урезаем `count` до реальной длины. 
В заголовки добавим в public:

В реализацию добавим:

MyString::MyString(const char* str, int count) : MyString() {
    if (str == nullptr) {
        throw std::invalid_argument("MyString: null pointer");
    }
    int length = static_cast<int>(std::strlen(str));
    if (count > length) {
        count = length;
    }
    replace_impl(0, 0, str, count);
}

MyString::MyString(const std::string& str, int count) : MyString(str.c_str(), count) {
}

MyString::MyString(const MyString& other, int count) : MyString(other.c_str(), count) {
}
```

У двух последних тело пустое `{ }`: вся работа уже сделана в конструкторе, которому они делегировали.
