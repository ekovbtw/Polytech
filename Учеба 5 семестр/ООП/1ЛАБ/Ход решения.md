# Шаг 1

Установка необходимый программ: clang++ (компилятор), python3, pybind11 (библиотека, которая связывает C++ и python), git. 

Создадим директорию проекта и инициализируем git:

```
mkdir mysting_lab 
git init
```

Создадим два служебных файла по условию: 

![[Pasted image 20261001184450.png]]

```
cat > mystring.h << 'EOF'
#ifndef _MYSTRING_H_
#define _MYSTRING_H_

class MyString {
};

#endif // _MYSTRING_H_
EOF
```

```
cat > mystring.cpp << 'EOF'
#include "mystring.h"
EOF
```

```
cat > main.cpp << 'EOF'
#include <iostream>
#include "mystring.h"

int main() {
    MyString str;
    std::cout << "Build OK" << std::endl;
    return 0;
}
EOF
```

**ifndef** (if not defined) - защита от повторного определения заголовка. Это может произойти, если препроцессор определяет сначала один заголовок в программе, а потом определяет этот же заголовок в другом заголовке. 
Пример: 
```
// utils.h 
#include "mystring.h" 
void PrintTwice(const MyString& str);
```
```
// main.cpp 
#include "mystring.h" 
#include "utils.h"

Тогда получается: 
// main.cpp
после подстановки class MyString { ... }; // из #include "mystring.h"
class MyString { ... }; // из utils.h, который тоже включил mystring.h 
void PrintTwice(const MyString& str);
```

Соберем программу: 

```
clang++ -std=c++17 -Wall -Wextra main.cpp mystring.cpp -o test_mystring
./test_mystring
```
`-std=c++17` — стандарт C++17, который требует code style; `-Wall -Wextra` включают предупреждения компилятора, они помогут ловить ошибки; `-o test_mystring` задаёт имя исполняемого файла.

Создадим python обертку: 

```
cat > MyString_wrapper.cpp << 'EOF'
#include <pybind11/pybind11.h>
#include "mystring.h"

namespace py = pybind11; // namespace - пространство имен, переименовали библиотеку в более короткую

PYBIND11_MODULE(mystring, m) // m - модуль с именем mystring
{
    py::class_<MyString>(m, "MyString") // в m - будет класс с именем "Mystring", сам класс <Mystring>
        .def(py::init<>()); .def - добавляет в класс, py::init<>() конструктор с пустым аргументом
}
EOF
```

**Обертка** (wrapper) - это программа, которая позволяет python использовать классы написанные на языке C++. После сборки получается модуль, который python подключает через import.
