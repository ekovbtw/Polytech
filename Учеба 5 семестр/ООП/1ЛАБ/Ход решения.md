## Классы, объекты 

**Класс** - это описание, как структура в C. 
**Объект** - конкретный экземпляр класса. 
В классе есть поля и методы. **Поля** - данные объекта (длина, переменные), **методы** - функции, с которыми работает объект. 
Класс решает проблемы связанные со структурами в языке C. 
Метод вызывается у объекта через точку:

```
a.clear()
int n = b.size()
```
Объект, в отличие от языка C, не передается явно.

Части класса можно закрыть от внешнего мира: 

```
class MyString {
public:               // доступно всем
    int size();
    void clear();

private:              // доступно только методам самого класса
    char* data_;
    int size_;
};
```
поля меняются только через методы, а методы написаны так, чтобы данные всегда оставались правильными.

Это называется **инкапсуляция**. 

**Конструктор** - особый метод, который самостоятельно вызывается при создании объекта. Его задача заполнить поля начальными значениями. 
1. У конструктора имя совпадает с именем класса
2. Нет возвращаемого типа

```
class MyString 
{ 
public: 
	MyString(); // конструктор без аргументов 
	MyString(const char* str); // конструктор от C-строки 
	...
};
```
Конструкторов может быть несколько, вызов конструктора зависит от типа объекта, который создается. 

```
MyString a;            // вызовется MyString()          → пустая строка
MyString b("hello");   // вызовется MyString(const char*) → строка "hello"
```
Самому вызывать конструктор не нужно и нельзя: он срабатывает ровно один раз, в момент рождения объекта. Забыть инициализацию теперь невозможно.

**Деструктор** - пара конструктора. Вызывается самостоятельно при уничтожении объекта. Его задача освободить ресурсы. 
Имя деструктора совпадает с названием класса с тильдой: `~MyString()`

Пример уничтожения объекта - заканчивается функция, в которой он был создан: 

```
{
    MyString s("hello");   // конструктор: выделили память
    ...
}                          // здесь деструктор: память освобождена
```

Создадим два служебных файла по условию:

```
cat > mystring.h << 'EOF'
#ifndef _MYSTRING_H_

class MyString {
};

#endif // _MYSTRING_H_
EOF

```
cat > mystring.cpp << 'EOF'
#include "mystring.h"

```
cat > main.cpp << 'EOF'
#include <iostream>
#include "mystring.h"

int main() {
    MyString str;
    std::cout << "Build OK" << std::endl;
    return 0;
}
EOF
```

**ifndef** (if not defined) - защита от повторного определения заголовка. Это может произойти, если препроцессор определяет сначала один заголовок в программе, а потом определяет этот же заголовок в другом заголовке. 
Пример: 
```
// utils.h 
#include "mystring.h" 
void PrintTwice(const MyString& str);
```
```
// main.cpp 
#include "mystring.h" 
#include "utils.h"

Тогда получается: 
// main.cpp
после подстановки class MyString { ... }; // из #include "mystring.h"
class MyString { ... }; // из utils.h, который тоже включил mystring.h 
void PrintTwice(const MyString& str);
```

Соберем программу: 

```
clang++ -std=c++17 -Wall -Wextra main.cpp mystring.cpp -o test_mystring
./test_mystring
```
`-std=c++17` — стандарт C++17, который требует code style; `-Wall -Wextra` включают предупреждения компилятора, они помогут ловить ошибки; `-o test_mystring` задаёт имя исполняемого файла.

Создадим python обертку: 

```
cat > MyString_wrapper.cpp << 'EOF'
#include <pybind11/pybind11.h>
#include "mystring.h"

namespace py = pybind11; // namespace - пространство имен, переименовали библиотеку в более короткую

PYBIND11_MODULE(mystring, m) // m - модуль с именем mystring
{
    py::class_<MyString>(m, "MyString") // в m - будет класс с именем "Mystring", сам класс <Mystring>
        .def(py::init<>()); .def - добавляет в класс, py::init<>() конструктор с пустым аргументом
}
EOF
```

**Обертка** (wrapper) - это программа, которая позволяет python использовать классы написанные на языке C++. После сборки получается модуль, который python подключает через import.
