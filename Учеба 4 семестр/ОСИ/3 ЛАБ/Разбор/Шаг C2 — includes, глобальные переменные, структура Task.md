#### Что меняется в объектах синхронизации

HANDLE mutex → pthread_mutex_t mutex (одна штука, логика та же)

HANDLE event и done_event → **два** pthread_cond_t. Один для уведомления потоков что появилась задача, второй для уведомления main что всё завершено. Оба работают на одном и том же mutex — это важное требование pthread_cond_wait.

Далее был выбран вариант, когда мы разбиваем массив на подмассивы, затем сортируем, а после того, как готовность всех массивов завершена, мы выполняем слияние.

#### Общая схема

1. Читаем массив из файла
2. Делим массив на global_count_threads равных кусков
3. Каждый поток берёт свой кусок и сортирует его целиком через mergesort
4. Ждём пока все потоки завершатся
5. Main последовательно сливает все куски в один отсортированный массив
