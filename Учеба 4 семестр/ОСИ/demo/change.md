В первом коде исправим перебор. Вместо того, чтобы заново начинать перебор знаков, будем перебирать начиная с "конца", если у одного варианта по отношению к следующему меняется только один знак. Достаточно поменять знак и прибавить/отнять удвоенное значение этого числа (у которого поменялся знак). Есть код "Грэя" - код, который гарантирует, что между вариантами будет отличаться только один знак (т.е. не будет таких вариантов, у которых следующий вариант отличается на более чем 1 знак). 
## Код грея
Сначала сделаем функцию, которая бы находила позицию первой включенной единицы.  
![[Pasted image 20260906180330.png]]
Весь набор знаков, можно представить в виде 1 и 0. Значит узнать знак, который стоит менять можно узнав позицию бита перешедшего из 0 в 1. Например:
![[Pasted image 20260906180841.png]]
```
int number_of_digits(LL task_index) // суть в том чтобы найти позицию первой еденицы справа 
{
	unsigned long Index;
	_BitScanForward64(&Index, (unsigned __int64)task_index);
	return (int)Index;
}
```
Функция возвращает первую единицу справа. Теперь нужно переделать логику под этот алгоритм.
