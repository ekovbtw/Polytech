# QuizMaster 🎓

Платформа для создания и прохождения тестов в стиле Quizlet/Kahoot.

## Быстрый старт

```bash
cd quiz-app
npm install
npm start
```

Откройте браузер: **http://localhost:3000**

## Структура

```
quiz-app/
├── server.js          # Express-сервер + API
├── quiz.db            # SQLite база (создаётся автоматически)
├── package.json
└── public/
    ├── index.html         # Главная страница
    ├── auth.html          # Вход / регистрация
    ├── dashboard.html     # Панель управления
    ├── create-test.html   # Создание / редактирование теста
    ├── take-test.html     # Прохождение теста
    ├── results.html       # Результаты студента
    ├── test-results.html  # Итоги теста (преподаватель)
    ├── css/style.css
    └── js/common.js
```

## Роли

| Роль | Возможности |
|---|---|
| **Преподаватель** | Создавать/редактировать/удалять тесты, видеть все попытки, экспортировать CSV |
| **Студент** | Находить тесты по коду, проходить, видеть свой результат |

## Настройки теста

- 🔒 **Вход по паролю** — только студенты с паролем могут пройти
- 👤 **Анонимный тест** — имя студента не требуется
- 📊 **Показ результатов** — студент видит/не видит оценку после сдачи
- 🔀 **Перемешать вопросы** — уникальный порядок для каждого студента
