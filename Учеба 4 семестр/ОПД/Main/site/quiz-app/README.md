# PolyMaker 🎓

Платформа для интерактивного обучения: классические тесты и Kahoot-режим в реальном времени.

## Быстрый старт

```bash
cd quiz-app
npm install
npm start
```

Откройте браузер: **http://localhost:3000**

---

## Маршрут пользователя

```
/ (лендинг)
  → /auth.html (вход / регистрация)
    → /mode-select.html (выбор режима)
      → /dashboard.html     (Режим тестов)
      → /kahoot.html        (Kahoot-режим)
```

## Роли

| Роль | Возможности |
|---|---|
| **Преподаватель** | Создавать/редактировать/удалять тесты, управлять классами, видеть все попытки, экспортировать вопросы в банк |
| **Студент** | Находить тесты по коду, проходить тесты, видеть результаты, состоять в классах |

## Возможности

### Тесты
- Несколько типов вопросов: одиночный выбор, множественный, текстовый ответ, числовой
- Настройка баллов за каждый вопрос
- Система оценок: автоматический расчёт порогов 3/4/5 (60% / 75% / 90%)
- Пароль к тесту, анонимный режим, перемешивание вопросов
- Ограничение по времени, дедлайн сдачи
- Показ / скрытие результатов для студента
- 6-символьный код для быстрого доступа

### Классы
- Преподаватель создаёт класс с кодом и опциональным паролем
- Студент вступает по коду или через приглашение
- Приглашение в класс: отправка → уведомление → принять / отклонить
- Назначение тестов классу с дедлайном

### Банк вопросов
- Создание банков, добавление вопросов вручную или экспорт из теста
- Генерация теста из банка

### Социальные функции
- Друзья: заявки, принятие/отклонение, список друзей
- Уведомления в реальном времени (🔔): заявки в друзья, приглашения в классы, дедлайны
- Поиск пользователей
- Настройки приватности: `show_profile`, `allow_invites`, `allow_friend_requests`

### Профиль
- Аватар, имя, фамилия, описание
- История попыток студента
- Управление заявками в друзья

### UI / UX
- Тёмная тема (сохраняется в `localStorage`)
- Адаптивный дизайн
- Фавикон на вкладке браузера

## API (основные эндпоинты)

### Авторизация
| Метод | URL | Описание |
|---|---|---|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/onboarded` | Отметить онбординг пройденным |

### Тесты
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/tests` | Мои тесты (преподаватель) |
| POST | `/api/tests` | Создать тест |
| PUT | `/api/tests/:id` | Обновить тест |
| DELETE | `/api/tests/:id` | Удалить тест |
| GET | `/api/public/tests/:code` | Найти тест по коду |
| POST | `/api/tests/:id/submit` | Сдать тест |
| GET | `/api/tests/:id/results` | Итоги теста (преподаватель) |

### Классы
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/classes` | Мои классы (преподаватель) |
| POST | `/api/classes` | Создать класс |
| POST | `/api/classes/join` | Вступить по коду |
| GET | `/api/my-classes` | Классы, в которых состоит пользователь |
| POST | `/api/classes/:id/invite` | Пригласить пользователя |
| GET | `/api/class-invites` | Входящие приглашения |
| POST | `/api/class-invites/:id/accept` | Принять приглашение |
| DELETE | `/api/class-invites/:id` | Отклонить приглашение |
| DELETE | `/api/classes/:id/leave` | Покинуть класс |

### Друзья
| Метод | URL | Описание |
|---|---|---|
| POST | `/api/friends/request` | Отправить заявку |
| GET | `/api/friends/requests` | Входящие заявки |
| GET | `/api/friends` | Список друзей |
| GET | `/api/friends/status/:username` | Статус дружбы |
| POST | `/api/friends/requests/:id/accept` | Принять заявку |
| DELETE | `/api/friends/:id` | Удалить друга / отменить заявку |

### Уведомления
| Метод | URL | Описание |
|---|---|---|
| GET | `/api/notifications` | Все уведомления |
| GET | `/api/notifications/unread-count` | Кол-во непрочитанных |
| PATCH | `/api/notifications/:id/read` | Отметить прочитанным |
| PATCH | `/api/notifications/read-all` | Отметить все прочитанными |

## Технологии

- **Backend:** Node.js, Express, better-sqlite3, JWT, bcryptjs, multer
- **Frontend:** Vanilla JS, HTML5, CSS3 (CSS Variables, Grid, Flexbox)
- **БД:** SQLite (файл `quiz.db`)
- **Порт:** 3000
