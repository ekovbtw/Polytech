В объектной модели Microsoft Word объект `Word.Application` описывает **само запущенное приложение** Microsoft Word со всеми его глобальными настройками, окнами и открытыми документами.

Основными «параметрами» этого объекта являются его **свойства (Properties)** и **методы (Methods)**.

Главные свойства (Настройки и коллекции)

- **`Visible`** (Boolean): скрывает или показывает окно Word на экране (`True`/`False`).
- **`Documents`** (Collection): коллекция всех открытых документов (главный путь к файлам).
- **`ActiveDocument`** (Document): возвращает текущий активный документ, с которым работает пользователь.
- **`Selection`** (Selection): выделенный в данный момент текст или позиция курсора.
- **`Options`** (Options): глобальные настройки Word (параметры сохранения, редактирования, проверки правописания).
- **`Version`** (String): возвращает номер версии установленного Word.

Главные методы (Действия)

- **`Quit()`**: полностью закрывает приложение Word и выгружает процесс из памяти.
- **`Run(MacroName)`**: запускает указанный макрос VBA внутри Word.
- **`CheckSpelling(Word)`**: проверяет орфографию переданного слова.

```
# 'word' — это объект класса Word.Application
word.Visible = True # Изменяем свойство Visible

# Используем метод Add() коллекции Documents, чтобы создать документ
doc = word.Documents.Add() 

# Печатаем текст через свойство Selection
word.Selection.TypeText("Привет, мир!") 

# Закрываем приложение методом Quit()
word.Quit()

```
С полным списком из сотен параметров, свойств и событий можно ознакомиться в официальной документации Microsoft Learn по Word.Application.
