Эти три функции — `QueryInterface`, `AddRef` и `Release` — составляют основу интерфейса **`IUnknown`**. В технологии COM абсолютно каждый интерфейс обязан наследоваться от `IUnknown`. Это значит, что в любой таблице VTable любого COM-объекта эти три метода гарантированно занимают самые первые три строчки.

Они всегда есть потому, что без них невозможно решить две главные проблемы распределенных программ: **управление временем жизни объекта** и **навигацию между его возможностями**.

AddRef и Realease — отвечают за управлением памятью. Изначально COM-объект может создать любая программа, а использовать несколько. Поэтому, чтобы было понятно, когда объект можно удалить ввели счетчики. AddRef (добавить ссылку) - инкремент простого счетчика программ, которые начинают использовать объект. Realease (удалить ссылку) - декремент простого счетчика программ, которые перестают использовать объект. Логично, что когда функция Realease выполниться и счетчик дойдет до нуля, то объект самоликвидируется. 

QueryInterface - Навигация по интерфейсам. COM-объект может выполнять несколько (множество) задач, соответственно, чтобы не хранить все функции в одном месте, их можно разделить на интерфейсы. Например: документ может сохранять, печатать или шифровать, соответственно интерфейсы: ISave, IPrint, IEncrypt. QueryInterface отвечает за то, чтобы программа поняла, какие интерфейсы есть у объекта. 
Порядок действий QueryInterface():
1. Ваша Программа спрашивает у объекта через этот метод: _«У тебя есть интерфейс `IEncrypt`? Вот его уникальный ID (IID - Interface Identifier)»_.
2. Объект проверяет себя.
3. Если такой интерфейс у него есть, он возвращает вам **новый указатель на новую таблицу VTable** (где лежат функции шифрования) и автоматически вызывает внутри себя `AddRef()`.
4. Если объект этого не умеет, он честно отвечает: _«Нет, такого интерфейса у меня нет»_ (возвращает ошибку `E_NOINTERFACE`), и ваша программа понимает, что данная функция недоступна.
```
// Примерная логика работы метода QueryInterface внутри объекта
HRESULT QueryInterface(IID riid, void** ppvObject) {
    if (riid == IID_IPrint) { 
        // Если попросили интерфейс печати, выдаем адрес таблицы VTable_Print
        *ppvObject = &VTable_Print; 
        AddRef(); // Увеличиваем счетчик ссылок
        return S_OK;
    }
    else if (riid == IID_ISave) { 
        // Если попросили интерфейс сохранения, выдаем адрес VTable_Save
        *ppvObject = &VTable_Save; 
        AddRef();
        return S_OK;
    }
    
    // Если объект такого не умеет:
    *ppvObject = NULL;
    return E_NOINTERFACE; 
}
```
